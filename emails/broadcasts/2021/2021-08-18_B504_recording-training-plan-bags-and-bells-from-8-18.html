Weekly Recommended Training Plan:

 

WEDNESDAY (8/18): Full Workout

 

 

THURSDAY (8/19): Recovery Focus

Perform the cool down from demonstrated at the end of our live training session. Depending on your time availability, you can either solely do the core temperature warm up (marching in place), or if you have more time, also perform the Joint Warm Up as well prior to this cool down.

  1. L4/L5 ELDOA x 1 min x 1 set
  2. L3/L4 ELDOA x 1 min x 1 set
  3. L5/S1 ELDOA x 1 min x 1 set

 

FRIDAY (8/20): Skill Development #1 and Stretching

  • Perform the Core Temperature Warm Up and/or the Joint Warm Up to start

Circuit: Perform 2-4 sets, resting up to 90 seconds:

  1. Bulgarian Bag Halo OR Halo with Counter Balance x 8-10 each side
  2. Bulgarian Bag Side Swing Squat OR Alternating Swing Squat x 6-15
  3. Lunge Stance Row or Coiled Row x 8-12 ea

Finish with this cool down as done in the workout:

  1. L4/L5 ELDOA x 1 min x 1 set
  2. L3/L4 ELDOA x 1 min x 1 set
  3. L5/S1 ELDOA x 1 min x 1 set

 

SATURDAY (8/21): Full Workout

  • Perform the workout as on Wednesday 

 

SUNDAY (8/22): Active Rest (OR Complete Off Day)

  • Easy walk outside/in nature (or anytime of day too) around your neighborhood for ~20-60 minutes remaining in nasal breathing throughout
  • Swimming: 15-20 minutes of pure unstructured movement in the water. Aim to move, wiggle all your joints, and play in the water freely. This is one of the best forms of recovery I've experienced personally over the years. 

Finish with this cool down:

  1. L4/L5 ELDOA x 1 min x 1 set
  2. L3/L4 ELDOA x 1 min x 1 set
  3. L5/S1 ELDOA x 1 min x 1 set

 

MONDAY (8/23): Skill Development #2, Conditioning, and Stretching

Circuit: Perform 3-6 sets of the following, resting up to 60 seconds:

  1. Bulgarian Bag Halo OR Halo with Counter Balance x 4-5 each side
  2. Kettlebell Half Kneeling Press OR Straddle Press x 8-10 ea
  3. Bulgarian Bag Side Swing Squat OR Alternating Swing Squat x 6-15 each side
  4. Lunge Stance Row or Coiled Row x 8-12 ea

Finish with this cool down:

  1. L4/L5 ELDOA x 1 min x 1 set
  2. L3/L4 ELDOA x 1 min x 1 set
  3. L5/S1 ELDOA x 1 min x 1 set
