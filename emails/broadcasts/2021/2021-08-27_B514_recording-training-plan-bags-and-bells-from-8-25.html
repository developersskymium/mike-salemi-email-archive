Weekly Recommended Training Plan:

 

WEDNESDAY (8/25): Full Workout

 

 

THURSDAY (8/26): Recovery Focus

Perform the cool down from demonstrated at the end of our live training session. Depending on your time availability, you can either solely do the core temperature warm up (marching in place), or if you have more time, also perform the Joint Warm Up as well prior to this cool down.

  1. T8/T9 ELDOA x 1 min x 1 set
  2. C6//C7 ELDOA x 1 min x 1 set
  3. L5/S1 ELDOA x 1 min x 1 set

 

FRIDAY (8/27): Skill Development #1 and Stretching

  • Perform the Core Temperature Warm Up and/or the Joint Warm Up to start
  • Perform each progression resting up to 60 seconds in between. For all of this work, begin to think more about your breathing rhythm, and how long it takes you to perform the reps designated. See if you can maintain a consistent number of breaths, as well as the duration of each breath within every rep of each progression. Also, stay nasal breathing throughout. 
  1. KB Deadlift x 10 x 1
  2. KB Two Hand Swing x 10-15 x 1
  3. KB Single Arm Swing x 10-15 ea x 1

 [LEVEL 1 Stop Here, LEVEL 2 Continue On]

  1. KB Clean x 10-12 ea x 1
  2. KB Half Snatch (Snatch Up, Lower Down Like a Press): x 10-12 ea x 1
  3. KB Snatch x 8-10 ea x 1-2
  • Once you've completed this, perform 1-3 sets of Abdominal Roll Ups for 10-15 quality reps. 

Finish with this cool down as done in the workout:

  1. T8/T9 ELDOA x 1 min x 1 set
  2. C6//C7 ELDOA x 1 min x 1 set
  3. L5/S1 ELDOA x 1 min x 1 set

 

SATURDAY (8/28): Full Workout

  • Perform the workout as on Wednesday, focusing heavily on your pacing strategy and breathing during the KB Snatch.

 

SUNDAY (8/29): Active Rest (OR Complete Off Day)

  • Easy walk outside/in nature (or anytime of day too) around your neighborhood for ~20-60 minutes remaining in nasal breathing throughout
  • Swimming: 15-20 minutes of pure unstructured movement in the water. Aim to move, wiggle all your joints, and play in the water freely. This is one of the best forms of recovery I've experienced personally over the years. 

Finish with this cool down:

  1. T8/T9 ELDOA x 1 min x 1 set
  2. C6//C7 ELDOA x 1 min x 1 set
  3. L5/S1 ELDOA x 1 min x 1 set

 

MONDAY (8/30): Skill Development #2, Conditioning, and Stretching

Station: Perform the following:

  1. KB Single Arm Swings OR KB Snatches x 30-60 seconds duration each arm (i.e. 60-120 seconds total per set of combined arm movements) x  2-4 sets at 1-2 minutes rest. *For Level II, even if you go at a slower pace, challenge yourself to last for 60 sec each arm, i.e a 2 minute set per each arm.

REST Up to 2 Minutes, before starting the circuit below. Rest as needed after each round.

  1. Bulgarian Bag Halo Lamb Swing OR Alt. Lamb Swing x 6-8 each x 1-3
  2. Kettlebell Bent Over Alt. Coiling Row (open palm grip) x 8-10 ea x 1-3
  3. Abdominal Roll Ups x 10-15 x 1-3

Finish with this cool down:

  1. T8/T9 ELDOA x 1 min x 1 set
  2. C6//C7 ELDOA x 1 min x 1 set
  3. L5/S1 ELDOA x 1 min x 1 set
